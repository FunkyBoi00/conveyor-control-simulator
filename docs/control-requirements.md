\# Conveyor control requirements\## States\- STOPPED: motor off, waiting for START.\- RUNNING: motor on, monitoring the part sensor.\- PAUSED: motor off during a three-second processing pause.\## Rules1\. The initial state is STOPPED.2\. STOP has priority over START and timer expiration.3\. START in STOPPED changes the state to RUNNING.4\. A rising edge of the part sensor in RUNNING starts PAUSED.5\. After three seconds in PAUSED, the state changes to RUNNING.6\. STOP in any state changes the state to STOPPED and cancels the timer.7\. START in RUNNING or PAUSED has no effect.8\. A sensor that remains active must not trigger repeated pauses.9\. If the sensor is active when START is pressed, the conveyor starts,&#x20;  but a new detection requires the sensor to become inactive and then active.10\. After STOP, a new START press is required to run again.\## Initial test scenarios\- START from STOPPED: motor turns on.\- START and STOP together: motor remains off.\- Sensor rising edge while RUNNING: motor stops for three seconds.\- STOP during PAUSED: motor remains off after the timer would have expired.\- Sensor held active: no repeated processing pauses.
